\section*{Introduction}
Phylogenies usually have leaf labels, and sometimes also labeled
internal nodes, like the example tree in Figure~\ref{fig:reno}A.
\begin{figure}
  \begin{center}
    \begin{tabular}{ccc}
      \textbf{A} & \textbf{B} & \textbf{C}\\
      \includegraphics{../reno/reno1} &
      \raisebox{1.25cm}{
      \begin{tabular}{ll}
        \hline
        Old & New\\\hline
        a & A\\
        b & B\\
        c & C\\
        d & D\\
        e & E\\\hline
      \end{tabular}
      }
      &
      \includegraphics{../reno/reno2}
  \end{tabular}
  \end{center}
  \caption{The program \ty{reno} relabels the nodes in phylogeny
    \textbf{A} according to table \textbf{B} to generate phylogeny
    \textbf{C}.}\label{fig:reno}
\end{figure}
The purpose of the program \ty{reno} is to rename the nodes of a
phylogeny. This is done by reading a phylogeny
(Figure~\ref{fig:reno}A) and a table of old and new names
(Figure~\ref{fig:reno}B). The old names are replaced by the new and
the phylogeny is printed again (Figure~\ref{fig:reno}C). The input and
output phylogenies are both in Newick format.

Our outline of \ty{reno} contains hooks for imports, functions, and
the logic of the main function.

Inside \ty{parse}, we retrieve the node names, and iterate over the
trees in the file. To each tree we apply the function \ty{rename}
before printing it.
#+end_export
#+begin_src go <<Functions, Pr. \ref{pr:reno}>>=
  func parse(r io.Reader, args ...interface{}) {
  	names := args[0].(map[string]string)
  	sc := nwk.NewScanner(r)
  	for sc.Scan() {
  		tree := sc.Tree()
  		rename(tree, names)
  		fmt.Println(tree)
  	}
  }

The function \ty{rename} recursively traverses the tree and wherever
it finds a matching old label, replaces it with the new one.
#+end_export
#+begin_src go <<Functions, Pr. \ref{pr:reno}>>=
  func rename(v *nwk.Node, names map[string]string) {
  	if v == nil {
  		return
  	}
  	newLabel := names[v.Label]
  	if newLabel != "" {
  		v.Label = newLabel
  	}
  	rename(v.Child, names)
  	rename(v.Sib, names)
  }
#+end_src
